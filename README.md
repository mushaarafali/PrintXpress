# PrintXpress

PrintXpress is an Android-based printing and order management application designed to simplify customized printing services, product management, customer orders, offers, and administrative operations.

## Features

### Customer
- User Registration & Login
- Browse Printing Products
- View Product Details
- Place Orders
- View Special Offers
- Track Orders
- Manage Profile

### Administrator
- Admin Dashboard
- Product Management
- Add & Edit Products
- Order Management
- Customer Management
- Offer Management
- Reports and Administrative Functions

## Technologies

- Java
- Android Studio
- XML
- Gradle
- Android SDK
